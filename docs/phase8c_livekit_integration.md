# Phase 8C-H: LiveKit Integration

## Integration Architecture
- **Audio Clock Synchronization:** TTS audio is fully decoded by `SyncTTSWrapper` which pushes PCM directly into `CanonicalMediaTimeline`.
- **Identity Encoder Checkpointing:** The identity encoder requires substantial computation. `NeuralRendererV3LiveKit` caches the hierarchical identity features (`self.identity_features`) during `initialize_avatar()`. This means the `IdentityEncoder` does *not* fire during real-time streaming steps, ensuring high-speed causal execution.
- **Media Pipeline:** `Audio -> AudioFeatures -> V4 -> V3 (Causal) -> VideoFrameScheduler -> LiveKit VideoSource`.
- **DiagnosticRenderer:** Preserved in `backend/engine/neural_renderer.py` as a fail-safe offline validator. 

## Media Clock
- **Canonical Audio Clock:** Frames are stamped with a strict `PTS` derived directly from `sample_position / sample_rate`.
- **Wall-clock usage:** The python `time.time()` scheduler in `VideoFrameScheduler` is strictly used for thread pacing/sleeping to prevent publishing queue saturation. It is deliberately isolated from the media timestamps.

## V3 Temporal State Control
- **Persistent State:** `(h_t, c_t)` generated by `ConvLSTMCell` persists sequentially across a contiguous speech turn.
- **Turn / Interruption Reset:** Calling `cancel_turn()` explicitly destroys `self.state = None`. Next speech generation immediately boots a clean `(0,0)` zero-state matrix, perfectly mitigating cross-turn visual corruption.
- **Sequence Reset:** Identical to Turn Reset.

## Local LiveKit Test Results
- **Audio:** Continuous and accurately segmented by `SyncTTSWrapper`.
- **Video:** The V3 engine generated 512x512 RGB blocks pushed via `VideoSource`.
- **Frame Order:** Monotonically ordered by canonical PTS.
- **Timestamps:** 0.040, 0.080, 0.120 etc., aligned perfectly with the 25FPS target.
- **Queue Bounds:** Stale turns gracefully dropped (e.g., returning `None` if `turn_id != self.current_turn_id`).

## Interruption Mechanics
When a user barges in, LiveKit signals a turn cancellation:
1. `feature_extractor`, `motion_predictor`, and `renderer` receive `cancel_turn(turn_id)`.
2. Turn A execution completely stops.
3. V3 `state` is wiped.
4. Turn B initiates completely pristine, generating neutral faces smoothly before progressing to new TTS audio.

## Silence Behavior
- **Neutral Rest:** The model accurately renders closed-mouth frames without drifting or jittering when V4 predicts dead silence.
- **Stability:** Maintained by the V3 recurrent smoothing block.
