# Known Limitations
1. 1280x720 is the current validated real-time target.
2. Extreme yaw >35° can still produce localized geometric artifacts.
3. Current user-perceived warm latency is ~906ms under tested service configuration.
4. Display/speaker physical latency beyond browser timing boundary is not directly measured.
5. 50-ID corpus is broader but not proof of universal human/lighting generalization.
6. Dedicated Viseme Transformer and Motion-Field Diffusion models are not used; current functional equivalents are V6 + eye dynamics + neural renderer.
