# v0.2.0 Release Notes

## WHAT CHANGED:
V8 -> V9 runtime spatial conditioning is now the default (`renderer_mode="v9_spatial"`).

## WHY:
V9 runtime spatial conditioning materially reduced the tested extreme-pose boundary artifacts while preserving normal-pose quality and real-time operation.

## PERFORMANCE:
- V8 ~17.5 ms
- V9 ~19.2 ms
- Safe 25 FPS maintained.

## CURRENT LIMITATION:
Localized artifacts can remain above extreme yaw ranges. The V9 mask does not resolve fully occluded background topologies lacking 3D depth buffers.

## ROLLBACK:
Configure `renderer_mode="v8_production"` to immediately regress to the frozen v0.1.0 visual architecture.
